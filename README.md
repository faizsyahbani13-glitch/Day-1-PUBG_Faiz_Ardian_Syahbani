## Kegiatan Workshop
Dokumentasi kegiatan workshop dapat dilihat pada bagian di bawah ini:
### 1. Rangkuman Materi
**Prompt Engineering**
Prompt adalah instruksi yang kita berikan ke AI. Agar hasilnya tepat, prompt perlu disusun dengan 4 unsur:
- **Role:** peran yang diminta dari AI
- **Task:** tugas yang ingin dicapai
- **Context:** kebutuhan dan batasan
- **Format:** bentuk hasil yang diinginkan

**Git dan GitHub**
- **Git:** alat di komputer untuk mencatat perubahan file (version control).
- **GitHub:** platform online untuk menyimpan repository Git dan berkolaborasi.

**Alur Kerja Git**
Working directory → Staging area → Repository.

### 2. Poin Penting
- Prompt yang spesifik dan punya konteks menghasilkan jawaban AI yang lebih baik.
- Git dan GitHub berbeda: Git adalah alatnya, GitHub adalah tempat penyimpanan onlinenya.
- Setiap perubahan disimpan lewat tiga langkah: `add`, `commit`, lalu `push`.
- Sebelum memakai Git, identitas (nama dan email) perlu diatur terlebih dahulu.
